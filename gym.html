Gym Guys: A highly scalable, AI-powered fitness application built natively for Android using Kotlin and Jetpack Compose. Engineered on a robust Clean Architecture foundation, the app leverages Firebase (Auth/Firestore) for secure, real-time NoSQL data synchronization, while integrating advanced Android Hardware Sensors for zero-latency step telemetry. Furthermore, the integration of Google Gemini AI provides a context-aware fitness assistant, paired with highly optimized Unidirectional Data Flow (StateFlow) and physics-based animations for a premium user experience.
