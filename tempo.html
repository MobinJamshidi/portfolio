< APP ARCHITECTURE & INFO />

Tech Stack: Kotlin Multiplatform · Compose Multiplatform (Android + iOS, single codebase) · Supabase (Auth, Postgres, Storage, RLS) · Koin (DI) · Ktor · Coil · kotlinx.datetime

Architecture Pattern: Clean Architecture per feature — data / domain / presentation layers, MVVM with unidirectional state flow (StateFlow → Compose UI).

feature/
  <feature_name>/
    domain/         → models, repository interfaces (contracts)
    data/           → DTOs, repository implementations (Supabase calls)
    presentation/   → ViewModels (StateFlow<UiState>)
    <FeatureName>Screen.kt  → Compose UI, stateless, reads ViewModel state

Repositories are bound to interfaces via Koin (single<XRepository> { SupabaseXRepository() }), ensuring the Supabase data source is fully swappable behind the domain contract.

> Cross-Cutting Concerns

  • Offline Handling: An expect/actual ConnectivityChecker is polled every 2s. If offline for ≥20s, a global OfflineScreen replaces the UI, avoiding flashes during brief network blips.
  • Error Messaging: Centralized translation from raw exception text (Postgrest/Auth errors) to user-facing copy, ensuring consistent UX without duplicating string-matching logic.
  • Dependency Injection: Koin modules are split by platform (appModule for commonMain, and androidModule for Android-only singletons like Context-dependent Notifiers).
