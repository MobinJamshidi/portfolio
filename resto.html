Resto Manager: A comprehensive offline-first system for restaurant management. Designed with a robust modular structure to handle employee records, shifts, financial ledgers, and inventory costs securely on the device.

Architecture:        MVVM + Feature-based modular structure
UI:                  100% Jetpack Compose (Material 3), no XML
State management:    StateFlow / Flow, ViewModel (AndroidViewModel)
Local persistence:   Room (per-feature databases) + Jetpack DataStore
Navigation:          Navigation Compose (single-activity architecture)
Async:               Kotlin Coroutines
Language:            Kotlin 100%
